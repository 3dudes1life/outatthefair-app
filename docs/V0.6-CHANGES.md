# V0.6 Together Edition

## New experience lab

- **Ask OATF:** an offline, private fair concierge for schedules, maps, accessibility, restrooms, quiet space, food and group planning
- **Together Mode:** William, Caleb and Daniel crew check-ins, rotating live statuses, meet-up beacon, group code and shareable plan
- **OATF Moments:** camera/photo upload, three branded frames, downloadable keepsake and Passport photo stamp
- **Fair Pulse:** live-style fairground updates, crowd-level meters and one-tap audience reactions
- **Memory Capsule:** personalized post-fair recap using saved events, Passport progress, crew check-ins and planner notes
- Six-step guided showcase tour updated to demonstrate the new Together Edition journey
- New universal-search results and PWA shortcuts for the V0.6 tools

## Preserved

- Cinematic launch and Showcase Fair Mode
- Animated OATF Pass
- My Day timeline
- Local demo notifications
- Dynamic Island / Lock Screen concept
- Fair pages, schedules, community, map, accessibility, Passport, planner and offline caching

## Data and privacy

V0.6 uses no user account and no remote tracking. Concierge history, crew status, planner information, reactions and memory-capsule state are stored locally on the device. Uploaded photos remain local unless the user explicitly downloads or shares a generated moment.
