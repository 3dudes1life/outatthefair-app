# V0.4 Changes

- Moves the OATF Model card below the hero description on phone screens so it never overlaps the headline or creates an oversized empty zone.
- Restores the floating card treatment on larger screens where there is room.
- Tightens hero typography, buttons and spacing for narrow iPhones.
- Adds native haptic feedback for navigation, favorites, planner tasks and passport stamps.
- Adds Android hardware-back support through the existing Capacitor App plugin.
- Applies a native light status-bar treatment over the app’s dark OATF chrome.
- Adds a Refresh App Content control without clearing saved user data.
- Migrates V0.3 local preferences and saved content automatically.
- Replaces `capacitor.config.ts` with `capacitor.config.json`, removing the TypeScript setup failure.
- Updates the offline cache and app version to 0.4.0.
