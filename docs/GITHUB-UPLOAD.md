# GitHub Upload — V0.6

Use `outatthefair-app-v0.6-github-upload.zip`.

1. Unzip it.
2. Open the unzipped folder.
3. In the `outatthefair-app` repository, choose **Add file → Upload files**.
4. Drag everything inside the folder into GitHub.
5. Replace matching files and commit to `main`.

The upload package excludes hidden files, including `.github`, `.gitignore` and `.nojekyll`. Your existing GitHub Pages workflow remains untouched. GitHub Actions does not require `.nojekyll` for this app.
