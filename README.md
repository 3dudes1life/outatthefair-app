# Out at the Fair® App — V0.7 Fair Companion

V0.7 makes the app meaningfully better than the website by turning it into the guest's live fair-day companion.

## New in V0.7
- Personalized guest dashboard
- Faster Fair Mode command center
- Happening Now / Up Next signals
- My Day, map, Together Mode, Passport and offers shortcuts
- Crew check-in summary
- Passport progress and saved schedule preview
- Partner offers with local save/redeem states
- Refined mobile spacing, cards and visual hierarchy
- Automatic migration from V0.6 local data

## Locked app identity
- Display name: `Out at the Fair`
- Bundle identifier: `com.outatinc.outatthefair`
- Version: `0.7.0`

## Open in Xcode
Extract the ZIP and run:

```bash
cd "$HOME/Downloads/outatthefair-app-v0.7" && chmod +x BUILD_V07_AND_OPEN_XCODE.command && ./BUILD_V07_AND_OPEN_XCODE.command
```

The script installs dependencies, creates or syncs the iOS project, reapplies the app display name and bundle identifier, and opens Xcode.
